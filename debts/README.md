# Наши долги — бот и мини-приложение в Telegram

Учёт кредиток, кредитов и займов на двоих.

**Мини-приложение**
- По центру — шкала **от 100 % до 0 %**: сколько всего осталось выплатить и сумма. Цветные полоски — отдельные карты, кредиты и займы, серая часть слева — то, что уже погашено.
- Ниже то же самое по каждому долгу отдельно, в карточках поменьше: процент, остаток, мини-шкала, ближайший платёж.
- Фильтр «Все / муж / жена / общие», экран платежей с историей, прогноз «без долгов к …», подсказка, что гасить первым.
- Отметить платёж, уточнить остаток, добавить или изменить долг.

**Бот**
- Пришлите **договор, график платежей, выписку или скриншот** (PDF или фото, можно альбомом) — бот через ИИ (Google Gemini) достанет кредитора, сумму, ставку, минимальный платёж и дату и сам заведёт долг. Документ прикрепится к долгу, его можно снова получить в чат из приложения.
- Пишите обычным языком: «заплатил 5000 по Тинькофф», «по карте Сбера сейчас 48 300», «потратила 3000 с кредитки».
- Спрашивайте совета: «что гасить первым?», «когда закроем все долги?», «стоит ли рефинансировать?»
- Напоминает о платеже обоим: за 3 дня, накануне, в день оплаты и при просрочке. Под напоминанием кнопка **«✅ Оплачено»**.
- Команды: `/summary` — сводка, `/next` — ближайшие платежи, `/reset` — начать разговор заново.

## Как устроено

| Где | Что |
|---|---|
| `debts/` | мини-приложение (HTML/CSS/JS без сборки). Вне Telegram работает в демо-режиме с примером данных |
| `supabase/functions/debts/` | серверная функция Supabase: вебхук бота, API приложения, напоминания, разговор с ИИ (`gemini.ts`, запасной `claude.ts`) |
| `supabase/migrations/20261102120000_debts.sql` | таблицы `debt*` (не пересекаются с таблицами «Плинтуса») |

Данные лежат в вашей базе Supabase. Договоры не хранятся у нас — в базе только ссылка на файл в Telegram; для разбора файл один раз отправляется в Gemini API от Google.

## Запуск (≈ 15 минут)

### 1. Бот и ключи
1. В [@BotFather](https://t.me/BotFather): `/newbot` → получите **токен бота**.
2. Бесплатный ключ Gemini: [aistudio.google.com](https://aistudio.google.com) → Get API key → Create API key. Из России сайт открывается только через VPN; сам бот потом работает без VPN.
3. Придумайте секрет (латиница и цифры), например: `openssl rand -hex 24`.
4. Telegram ID — свой и жены. Узнать можно у [@userinfobot](https://t.me/userinfobot) или позже: бот сам пришлёт ID любому, кого ещё нет в списке.

### 2. База
Supabase → **SQL Editor** → по очереди выполните файлы из `supabase/migrations/` (все `*debt*`): таблицы, служебный ключ для расписания и права для серверной функции. В новых проектах Supabase таблицы по умолчанию закрыты даже для серверной роли — без последнего файла бот не увидит базу.

### 3. Секреты и деплой функции
Supabase → **Edge Functions → Secrets** (или через CLI):

```bash
supabase secrets set --project-ref uizymjtflqoicpnifoue \
  DEBTS_BOT_TOKEN="123456:ABC..." \
  DEBTS_SECRET="ваш-секрет" \
  DEBTS_ALLOWED_IDS="111111111,222222222" \
  DEBTS_APP_URL="https://klimgr.github.io/delo/debts/" \
  GEMINI_API_KEY="AIza..."

supabase functions deploy debts --project-ref uizymjtflqoicpnifoue --no-verify-jwt
```

Необязательные настройки: `DEBTS_TZ` (по умолчанию `Europe/Moscow`), `DEBTS_GEMINI_MODEL` (по умолчанию `gemini-flash-latest` — свежая модель Flash, доступная бесплатно).

### 4. Подключить бота
Откройте в браузере (подставьте свой секрет):

```
https://uizymjtflqoicpnifoue.supabase.co/functions/v1/debts/setup?key=ваш-секрет
```

Это подключит вебхук, команды и кнопку «Долги» в меню бота. В ответ придёт `"ok": true` и имя бота.

### 5. Напоминания каждый день в 10:00 по Москве
Расширения `pg_cron` и `pg_net` должны быть включены (Database → Extensions). Затем в SQL Editor:

```sql
select cron.schedule('debts-reminders', '0 7 * * *', $job$
  select net.http_post(
    url := 'https://uizymjtflqoicpnifoue.supabase.co/functions/v1/debts/cron',
    headers := jsonb_build_object('Content-Type', 'application/json',
      'x-cron-key', (select value from public.debt_settings where key = 'cron_key')),
    body := '{}'::jsonb
  );
$job$);
```

`0 7 * * *` — это 07:00 UTC = 10:00 МСК. Ключ `cron_key` база сгенерировала сама (миграция `debt_settings`), копировать его никуда не нужно.

### 6. Мини-приложение
Папка `debts/` публикуется вместе с сайтом репозитория (GitHub Pages) по адресу `https://klimgr.github.io/delo/debts/` — этот адрес и нужно указать в `DEBTS_APP_URL`. Если Pages ещё не включён: Settings → Pages → Deploy from a branch → `main`.

### 7. Начать
Вы и жена открываете бота и нажимаете **«Старт»** — без этого Telegram не даст боту писать напоминания. Дальше просто пришлите первый договор.

## Если что-то не работает

- **Бот молчит** — откройте `/setup?key=…` ещё раз и проверьте логи функции в Supabase (Edge Functions → debts → Logs).
- **«Нет доступа» в приложении** — ID не добавлен в `DEBTS_ALLOWED_IDS`. Приложение покажет ваш ID — добавьте его в секрет.
- **«ИИ пока не подключён» или «Ключ ИИ не подошёл»** — проверьте `GEMINI_API_KEY`. Сводка `/summary`, `/next`, напоминания и приложение работают и без него.
- **«Бесплатный лимит ИИ закончился»** — у бесплатного тарифа Google есть лимит запросов в минуту и в день; подождите минуту или до завтра.

## Про ИИ

По умолчанию бот работает на **Google Gemini** по бесплатному тарифу. На бесплатном тарифе Google может использовать присланные документы для улучшения своих моделей, а их могут просматривать сотрудники Google. Если это важно, закрывайте паспортные данные на фото перед отправкой или подключите платный тариф.

Запасной вариант — **Claude** (платный API Anthropic). Задайте `ANTHROPIC_API_KEY` и `DEBTS_AI=claude`, и бот переключится без переделок. Для Claude по умолчанию используется Claude Opus 5.5 (`DEBTS_MODEL`) со средним уровнем размышлений (`DEBTS_EFFORT`) и включённой серверной резервной моделью (`fallbacks: "default"`).

Советы бота — общие рекомендации на основе ваших цифр, а не индивидуальная финансовая консультация.

## Разработка

Посмотреть интерфейс: откройте `debts/index.html` через любой локальный сервер (`python3 -m http.server` в папке `debts`) — будет демо-режим с примером данных, хранится только в браузере.

Тесты сервера (без сети: Gemini, Claude, Telegram и база подменяются):

```bash
deno test --allow-env supabase/functions/debts/
```

Логика сроков платежей есть в двух местах — `supabase/functions/debts/logic.ts` и в `debts/app.js` (для демо-режима). Меняя одну, меняйте и другую.
